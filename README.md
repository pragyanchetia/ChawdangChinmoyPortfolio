## Overview

This portfolio website is designed for **Chawdang Chinmoy, a cinematographer**, with one main goal: let the work take center stage. The interface presents projects and visual media in a dedicated portfolio experience instead of burying them in a conventional text-heavy website.

The project is built with Next.js and React, with reusable interface components and custom styling to keep the presentation cohesive.

## Highlights

- **Work-focused presentation** — a dedicated work section for showcasing creative projects.
- **Portfolio landing page** — an introductory hero experience that gives visitors a starting point.
- **Reusable UI components** — navigation, about, contact, footer, work, and testimonial components are separated for easier maintenance.
- **Media support** — includes video and image assets for rich visual storytelling.
- **Motion and visual polish** — includes AOS, React Player, and Swiper dependencies for animated and carousel-style experiences where implemented.
- **Styling flexibility** — custom CSS and Tailwind CSS utilities support layout and visual refinement.

## Getting Started

### Prerequisites

- Node.js and npm installed.

### 1. Clone the repository

```bash
git clone https://github.com/pragyanchetia/ChawdangChinmoyPortfolio.git
cd ChawdangChinmoyPortfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production build

```bash
npm run build
npm start
```
